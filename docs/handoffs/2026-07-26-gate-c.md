### Tier 1 — the three divergences from vendor practice (do first)

Each recommends something most or all surveyed vendors do *not* do. Each now
carries fresh Gate B evidence. Each is genuinely arguable — someone weighting
ecosystem compatibility above standards alignment could reasonably invert any.

1. **`AC-003`** — mandate RFC 9457 `application/problem+json` for errors.
   Only **1 of 8** surveyed vendors does. Gate B *strengthened* this
   (confidence raised to high-moderate): ASP.NET Core emits ProblemDetails **by
   default**, Spring via one property, and Microsoft's framework default
   contradicts Microsoft Graph's proprietary shape.
2. **`OP-016`** — prefer RFC 9421 HTTP Message Signatures for webhooks.
   **0 of 8** adoption. Gate B *raised* it: Cloudflare ships RFC 9421
   verification in production (Web Bot Auth), backed by Cloudflare/Amazon/
   Akamai/OpenAI — **but for inbound bot auth, not webhook consumers**, so it
   stays "prefer," not "must."
3. **`OP-010`** — emit IETF `RateLimit`/`RateLimit-Policy` fields.
   **0 of 8** adoption. Gate B *lowered* it: the HTTPDIR "Not Ready" verdict is
   **editorial, not design** ("the technical design presented seems sound"), but
   the draft has run 7 years without Last Call and **expires 2026-11-24**.
   Carries an explicit expiry contingency.

## 🧠 Critical context that won't survive a fresh window

### Decisions made, and why

- **Two research series are kept deliberately, and differ in *kind*.** `survey`
  is **descriptive** (what 8 reference APIs do; makes no recommendations);
  `baseline` is **prescriptive** (what this standard should require). Do not
  merge them. A survey report that recommends a rule has exceeded its mandate.
- **A `baseline` report proposes; it does not ratify.** None of the 66
  principles is policy. Gate C is precisely the moment that changes.
- **Flat research layout, paired by filename stem** —
  `<series>-<seq>-<topic>.<role>[.<date>[<letter>]].md`. Chosen because the user
  wanted flat (easier for an agent to find than nested dirs) and because pairing
  then becomes a glob rather than an index lookup.
- **Both runs of twice-run prompts are retained** (`survey-01`, `survey-06`).
  Divergence between independent runs is a confidence signal, not noise.

### Conventions and preferences agreed this session

- **Decide one at a time.** The user asked explicitly for decision-by-decision on
  Gate C, not a batch.
- **Verify with 2+ sources, primary preferred** — vendor-primary (e.g. Microsoft
  Learn, a project's own repo/blog) or standards bodies (IETF Datatracker, IANA,
  W3C). This is a hard rule, not a preference, and it earned its keep: **two of
