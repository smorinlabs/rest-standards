# rest-standards

A reusable, language-agnostic standard for designing consistent HTTP/REST APIs.

The repository is currently in its planning and research phase. Start with
[`PLAN.md`](PLAN.md), then read [`research/README.md`](research/README.md) for
the research inventory and naming convention.

Research is organized as two series under [`research/`](research/): a
descriptive `survey` series comparing eight reference APIs against the
standards they implement, and a prescriptive `baseline` series proposing the
rules this standard should adopt.

No normative REST standard has been drafted yet. Research execution and policy
decisions are explicit approval gates in the plan.
