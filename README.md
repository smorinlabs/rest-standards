# rest-standards

A reusable, language-agnostic standard for designing consistent HTTP/REST APIs.

The normative standard is [`rest-api-standard.md`](rest-api-standard.md)
(v1.1.2), released 2026-08-10 and amended under its own Part II rule. Start
with [`PLAN.md`](PLAN.md), then read [`research/README.md`](research/README.md)
for the research inventory and naming convention.

Research is organized as two series under [`research/`](research/): a
descriptive `survey` series comparing eight reference APIs against the
standards they implement, and a prescriptive `baseline` series proposing the
rules this standard should adopt.

The `rest-standards` agent skill applies it in four modes — see
[`docs/skills/rest-standards.md`](docs/skills/rest-standards.md). Research
execution and policy decisions are explicit approval gates in the plan.
